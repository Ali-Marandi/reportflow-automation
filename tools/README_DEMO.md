# Integrated Demo

This script demonstrates how all three tools (`customize_template`, `manage_data_sources`, and `automate_scheduling`) work together to build a complete automation pipeline.

## What it does:
1.  **Customizes** the HTML template with a specific theme color and company name.
2.  **Manages** data sources by programmatically adding a CSV file to the configuration.
3.  **Executes** the report generation as a scheduled task would.

## How to run:
```bash
python integrated_demo.py
```
After running, check the `demo_project/output` directory for the results.
